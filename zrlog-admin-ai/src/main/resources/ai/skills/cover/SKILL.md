# 生成文章封面

## 执行步骤

1. 从文章与用户要求中确定画面主题。已有明确风格、主体或配色要求时传入 `instruction`；没有指定风格时，直接采用生成器的默认构图。
2. 调用 `writing_cover`。图片生成服务负责实际生成，封面比例来自现有设置；文字回答不能代替图片结果。
3. 成功后引导用户查看封面预览，需要时使用已有裁剪和应用操作。不得编造图片地址，也不能声称候选已经上传或设为封面。
4. 服务返回配置或生成错误时说明本次未生成成功，不以虚构的图片链接补位。

## 使用示例

“给这篇露营游记生成一张暖色调插画封面”：调用 `writing_cover`，将暖色调与插画风格作为生成要求，无需先索取一份完整绘图提示词。
