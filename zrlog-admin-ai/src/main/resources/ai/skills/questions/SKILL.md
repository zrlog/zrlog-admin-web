# 发现读者疑问

## 执行步骤

1. 用户指定读者群体时，在 `instruction` 中注明；没有指定时，依据文章主题和表达判断，不因此阻塞任务。
2. 调用 `writing_questions`，查看返回的问题、疑问原因和补充建议。
3. 将这些问题作为编辑线索介绍给用户；它们是基于文章推测的疑问，不是真实读者反馈。
4. 发现缺少的数据、经验或案例时，说明需要作者提供的材料，不擅自编写答案并插入文章。

## 使用示例

“站在第一次接触这个技术的读者角度，看看哪些地方没讲清楚”：调用 `writing_questions`，传入读者背景。
