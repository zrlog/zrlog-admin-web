# 发布前检查

## 执行步骤

1. 调用 `writing_publishCheck`，把用户关心的问题放入 `instruction`。文章字段来自编辑器，发布相关配置由服务端补充。
2. 依据返回的检查结果说明需要处理的问题，以及哪些建议只是可选改进。
3. 对未实际检测的链接可达性、事实真实性或上线结果，不作已经验证的承诺。
4. 检查结束后返回报告。用户另有保存或发布要求时，使用相应文章工具及其审批流程；检查分数本身不构成发布授权。

## 使用示例

“发布前帮我检查有没有明显遗漏”：执行 `writing_publishCheck` 并说明检查结果，到此完成检查任务。
