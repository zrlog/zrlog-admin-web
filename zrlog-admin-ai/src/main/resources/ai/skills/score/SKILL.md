# 评估文章质量

## 执行步骤

1. 判断用户想看整体质量评价，还是某个专项问题。错别字、搜索展示和发布检查分别有对应技能。
2. 调用 `writing_score`；用户指定评价重点时，将其放入 `instruction`。
3. 根据评分结果说明最值得改进的地方。评分是基于当前草稿的编辑建议，不能作为事实已核实或文章已经发布的证明。
4. 用户只要求评价时，给出报告即可；不要自动接着重写文章。

## 使用示例

“给这篇文章打个分，重点看看新手能否读懂”：调用 `writing_score`，传入可读性方面的要求。
