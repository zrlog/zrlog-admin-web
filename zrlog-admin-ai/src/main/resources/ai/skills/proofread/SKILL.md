# 校对文章文字

## 执行步骤

1. 确认校对范围；用户已选中或明确指定片段时，在 `instruction` 中注明该范围。
2. 调用 `writing_proofread`，依据返回的原文片段、问题和修改建议说明发现。
3. 校对报告本身不会替换正文。用户要求整理全文时，可使用正文整理技能；只要求找错误时，不自动重写。
4. 将文字表达问题与需要外部证据的事实核验区分开，不把校对结果当作事实核实结论。

## 使用示例

“检查这篇文章的错别字和标点，先列出问题”：调用 `writing_proofread`，返回问题清单供用户审阅。
