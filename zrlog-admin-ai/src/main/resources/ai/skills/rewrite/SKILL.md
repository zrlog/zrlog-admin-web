# 整理已有正文

## 执行步骤

1. 检查编辑器中是否已有可整理的草稿。当前处理器要求去除首尾空白后的正文至少 120 个字符；不足时，请用户先在编辑器补充正文。
2. 提取用户希望改善的问题。如果用户选中了片段，将其作为关注范围，并在 `instruction` 中说明范围；处理器仍返回整篇正文候选。
3. 调用 `writing_rewrite`。将用户给出的语气、读者和修改范围传入要求；泛指“润色一下”时可以直接处理，无需先问一组风格问题。
4. 根据返回的修改说明介绍变化，供用户在正文对比中查看。没有用户要求时，不连带生成新标题、摘要或封面。

## 使用示例

“把这篇教程整理得更适合初学者，重点改开头”：调用 `writing_rewrite`，传入读者和重点范围，保留用户自行审阅正文候选的步骤。
