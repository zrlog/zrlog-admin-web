# 生成文章摘要

## 执行步骤

1. 确认用户需要的是文章摘要，提取其关注点、篇幅和读者要求。
2. 调用 `writing_digest`，把这些要求放入 `instruction`。通常直接依据当前文章生成，不需要先生成或选择标题。
3. 如果用户已经选定标题，或指定某个叙述角度，在要求中明确写出；不要把尚未选定的标题当作事实。
4. 依据返回结果回应用户。生成器读取当前编辑器内容，不能假定之前生成的正文候选已经应用。

## 使用示例

“给这篇文章写一段适合列表页的简短摘要”：直接调用 `writing_digest`，不额外询问标题、风格等可从上下文判断的信息。
