# 生成文章别名

## 执行步骤

1. 区分文章显示标题与 URL 别名；用户只想改标题时使用标题技能。
2. 调用 `writing_alias`。用户指定了需要保留的词或命名偏好时，将其写入 `instruction`。
3. 展示返回的别名候选。此操作不检测路径是否已被占用，也不证明现有公开链接已经改变。

## 使用示例

“帮这篇文章生成一个简短的英文 URL 别名”：根据当前文章调用 `writing_alias`，无需让用户先写一份英文标题。
