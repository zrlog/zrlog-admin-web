# 分析文章结构

## 执行步骤

1. 提取用户关注的结构问题，例如开头过长、章节顺序混乱或结尾缺少收束。
2. 调用 `writing_structure`，传入这些问题；泛指“结构怎么样”时可以直接分析。
3. 依据报告说明建议调整的位置和原因。建议新增内容时，应指出需要作者补充哪些材料，不能把建议当作现有事实。
4. 用户只要求分析时保留建议即可；用户要求实际整理正文时，再把相关建议传给正文整理技能。

## 使用示例

“检查这篇教程的章节顺序，先给我调整建议”：调用 `writing_structure`，不自动替换正文。
