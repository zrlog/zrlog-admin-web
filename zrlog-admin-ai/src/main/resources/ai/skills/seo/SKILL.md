# 检查文章 SEO

## 执行步骤

1. 提取用户明确给出的目标主题或搜索词；没有指定时，基于当前文章检查，不必先索取关键词清单。
2. 调用 `writing_seo`，传入这些关注点。
3. 根据检查结果解释可改进的文章字段。此技能评估当前内容，不提供搜索排名、搜索量或抓取状态的实测数据。
4. 用户要求生成某个字段的改进稿时，再调用对应写作技能，并传入本次检查中相关的建议。

## 使用示例

“看看这篇文章的标题和摘要适不适合搜索展示”：调用 `writing_seo`，把标题与摘要匹配作为检查重点。
